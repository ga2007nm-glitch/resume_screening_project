About This Project

What is AI Resume Screener?

An intelligent recruitment tool built with Python that analyzes resumes, calculates ATS scores, matches candidates to companies, and recommends suitable job roles.

Technologies Used

Backend: Python, FastAPI, PyPDF2
Frontend: HTML, CSS, JavaScript, Font Awesome
AI: Keyword extraction, skill matching, company recommendation engine

Features

ATS Score · Skill Gap Analysis · Company Recommendations · Job Role Suggestions · Resume Generator · Notifications
